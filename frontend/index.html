01

Singleton Pattern

Class: MovieDatabase.java

Ensures that only one centralized in-memory database instance exists across the entire application lifecycle with a private constructor and a static getInstance() accessor.

Instance Hash: --
Catalog Movies: -- 
public class MovieDatabase {
    private static MovieDatabase instance;
    private List<Movie> movies;
    private MovieDatabase() { ... }
    public static synchronized MovieDatabase getInstance() {
        if (instance == null) instance = new MovieDatabase();
        return instance;
    }
}
02

Factory Method Pattern

Class: MovieFactory.java

Encapsulates the instantiation logic of Movie objects, decoupling data parsing and construction from business services. Handles raw pipe-delimited data conversion.

Factory Methods: createMovie(), createFromFile() 
public class MovieFactory {
    public static Movie createMovie(int id, String title, ...) {
        return new Movie(id, title, genre, language, rating, year, platform);
    }
    public static Movie createMovieFromFile(String line) {
        String[] parts = line.split("\\|");
        return new Movie(Integer.parseInt(parts[0]), parts[1], ...);
    }
}
03

Observer Pattern

Subject: NotificationService | Observer: UserObserver

Defines a one-to-many publish-subscribe dependency so that when a new movie is added or an admin broadcasts, all registered user observers are automatically notified.

Subscribed Observers: --
Broadcast History: -- 
interface Subject {
    void addObserver(Observer o);
    void notifyObservers(String msg);
}
class NotificationService implements Subject {
    public void notifyObservers(String msg) {
        for (Observer o : observers) o.update(msg);
    }
}
04

Protection Proxy Pattern

Proxy: MovieServiceProxy | Real: RealMovieService

Controls access to sensitive movie mutation operations. Regular USER roles are blocked with 403 Forbidden before reaching the RealMovieService. Only ADMIN is authorized.

Admin Rights: Full Add / Remove / Broadcast
User Rights: Read-Only (Mutations Blocked) 
class MovieServiceProxy implements MovieService {
    public void addMovie(Movie movie) {
        if ("ADMIN".equalsIgnoreCase(role)) {
            realService.addMovie(movie);
        } else {
            throw new SecurityException("Access Denied!");
        }
    }
}
05

Chain of Responsibility Pattern

Handlers: GenreHandler → LanguageHandler → RatingHandler → PlatformHandler

Decouples the recommendation sender from multiple filtering processors. Each handler in the chain processes the filtered subset of movies and delegates the result to its successor handler.

Handler 1

GenreHandler

Filters movie list by selected Genre or passes all if "Any".

Handler 2

LanguageHandler

Filters remaining list by English, Hindi, or passes all if "Any".

Handler 3

RatingHandler

Filters remaining list by minimum IMDb score threshold.

Handler 4

PlatformHandler

Filters remaining list by OTT streaming service (Netflix, Prime, etc.).

Strategy Pattern

Context: CatalogSorterContext | Interface: MovieSortStrategy

Encapsulates dynamic catalog sorting algorithms into interchangeable strategy classes. Strategies can be swapped at runtime without altering client code.

Available Strategies: Rating, Year, Title, Binge Score

class YearSortStrategy implements MovieSortStrategy { ... }
07

Template Method Pattern

Abstract Template: WatchlistReportTemplate

Defines the invariant skeleton of a watchlist report algorithm in final generateReport(), deferring header, row, and footer formatting to concrete subclass generators.

Algorithm Skeleton: final generateReport()
Concrete Formats: Markdown, Text, JSON 
public abstract class WatchlistReportTemplate {
    public final String generateReport(...) {
        append(formatHeader());
        append(formatRows());
        append(formatFooter());
    }
}
